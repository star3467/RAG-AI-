# 切塊（Chunking）

- C20：切塊就是把長文件切成較小的單位，每一塊都可以單獨被索引、嵌入與檢索。 [S6]
- C21：Anthropic 描述的標準做法是把知識庫切成塊，每塊通常不超過數百個 token。 [S3]
- C22：切塊大小有拉扯：小塊（約 100–256 token）有利於精準比對；大塊（約 1024 token 以上）能給 LLM 比較完整的上下文。 [S6]
- C23：常見做法（經驗法則，非實驗結論）：多數情況用 300–500 token 的塊，相鄰塊重疊 10–20%；例如 500 token 的塊重疊 50–100 token。 [S6]
- C24：常見切法有固定長度、遞迴（依段落／句子逐層切）、語意切塊（在語意轉折處切）、以及保留文件結構（章節、表格）的切法。 [S6]
- C25：塊的大小、邊界與重疊方式都會影響檢索表現，需要依資料實測調整。 [S3]

⚠ 注意：C23 的數字來自教學文章（S6），簡報中要標示為「常見做法」，不要說成「最佳值」。
