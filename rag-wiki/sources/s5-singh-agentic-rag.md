# 摘要
回顧 RAG 範式演進（Naive → Advanced → Modular → Graph → Agentic），說明傳統 RAG 在上下文整合、多步推理、延遲三方面的限制，介紹四種代理設計模式（反思、規劃、工具使用、多代理協作）與 Corrective／Adaptive 等架構，最後整理實務教訓。
