# RAG 是什麼（定義與動機）

- C01：大型語言模型只靠訓練資料回答，知識停在訓練截止點，遇到新資訊或冷門領域時可能過時，也可能編造看似合理的內容（幻覺）。 [S4][S5]
- C02：RAG（檢索增強生成）的做法是：回答之前先從外部知識庫找出相關資料，附加到使用者的提示詞裡，再讓語言模型據此生成答案。 [S3][S4]
- C03：「RAG」這個名稱來自 2020 年 Lewis 等人的論文，他們把預訓練的生成模型（參數記憶）和 Wikipedia 的稠密向量索引（非參數記憶）接在一起。 [S1][S2]
- C04：參數記憶是存在模型權重裡的知識；非參數記憶是放在外部、可直接修改的索引。換掉外部索引就能更新知識，不需要重新訓練模型。 [S1]
- C05：RAG 的三項主要好處：有依據（答案連到可查證的資料，降低幻覺）、可擴展（同一個模型可以靠換知識庫適應不同領域）、成本較低（不必為每次知識變動重新微調）。 [S4]
- C06：Gao 等人整理出 LLM 在實務上的三個痛點：會產生幻覺、知識更新慢、答案不透明。RAG 是針對這些痛點的主流解法。 [S2]
- C16：Lewis 等人比較了兩種形式：整段輸出都參考同一批檢索到的段落，或是每個 token 可以參考不同段落。 [S1]
