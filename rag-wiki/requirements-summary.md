# 需求摘要

> 日期：2026-11-23。**這是 ingest 完成後補做的設計訪談的摘要**，並非 ingest 前實際發生的對話。

| 面向 | 需求 |
|---|---|
| 讀者 | 修習 LLM 課程的學生、RAG 初學者；兼顧技術正確性與易讀性 |
| 頁面類型 | Sources、Concepts、Index、Schema、Log，讓來源、概念、製作過程都可追蹤 |
| 語言 | 繁體中文為主，保留必要英文技術名詞 |
| 出處 | 每項重要主張標註來源編號；實驗數字要能回原始來源核對，不用未確認的二手數據 |
| 矛盾處理 | 先查原始論文／官方文件；無法確認就記錄差異與不確定性，不自選數字 |
| ingest 方式 | 逐篇：整理來源 → 擷取 claim → 更新概念頁與索引 → 跑 lint |
| 產出 | 18 頁 HTML 教學簡報（原理、檢索流程、進階技術、風險、小測驗），每頁可追溯 claim |
| lint | claim 編號不重複、有來源、來源宣稱的 claim 存在、索引計數正確；簡報的 claim、數字、網址正確 |

## 對照：需求與這次實際執行
- 符合：出處規則、矛盾處理（Contextual Retrieval 數字衝突時改讀原文）、頁面類型、產出。
- 有落差：需求寫「每篇 ingest 後跑 lint」，**實際是 6 篇收完才第一次跑**，index 計數錯誤因此晚發現。
- 對應到 AGENTS.md：上面的需求已寫成其中的 ingest 規則與完成的定義。
