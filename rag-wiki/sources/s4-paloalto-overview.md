# 摘要
用淺顯方式說明 RAG 的運作（查詢編碼、資料索引、文件檢索、脈絡增強、回應生成）、三項好處（grounding、可擴展、成本效率）、典型用途、與微調／提示工程的比較，以及四種資安風險（資料投毒、提示注入、敏感資料外洩、外部 API 依賴）。
